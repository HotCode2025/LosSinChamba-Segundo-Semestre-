## 📋 Descripción

Proyecto desarrollado por **Los Sin Chamba**, un equipo de programadores dedicados a crear soluciones web elegantes y funcionales. Esta página web fue construida utilizando Vue.js, JavaScript puro y CSS, demostrando nuestras habilidades en desarrollo frontend moderno.

## 🎯 Objetivo del Proyecto

Crear una página web interactiva que represente a nuestro equipo de desarrollo, mostrando:
- Presentación del equipo
- Portfolio de proyectos
- Habilidades técnicas
- Información de contacto

## 🛠️ Tecnologías Utilizadas

### Core
- **Vue.js 3.x** - Framework progresivo de JavaScript
- **JavaScript (ES6+)** - Lenguaje de programación
- **CSS3** - Estilos y diseño responsive

### Características Técnicas
- ✅ Single Page Application (SPA)
- ✅ Componentes reutilizables
- ✅ Diseño responsive
- ✅ CSS puro (sin frameworks como Bootstrap o Tailwind)
- ✅ JavaScript vanilla para funcionalidades personalizadas

## 🚀 Instalación y Configuración

### Prerequisitos

Antes de comenzar, asegúrate de tener instalado:
- Node.js (v14 o superior)
- npm o yarn

### Pasos de Instalación

1. **Clonar el repositorio**
```bash
git clone https://github.com/tu-usuario/los-sin-chamba.git
cd los-sin-chamba
```

2. **Instalar dependencias**
```bash
npm install
# o
yarn install
```

3. **Ejecutar en modo desarrollo**
```bash
npm run dev
# o
yarn dev
```

4. **Compilar para producción**
```bash
npm run build
# o
yarn build
```

## 💻 Proceso de Desarrollo

### 1. Planificación
- Definición de la estructura del sitio
- Diseño de wireframes y mockups
- Selección de paleta de colores y tipografías

### 2. Configuración Inicial
- Creación del proyecto con Vite/Vue CLI
- Estructura de carpetas y archivos
- Configuración de variables CSS globales

### 3. Desarrollo de Componentes
Creamos componentes Vue modulares y reutilizables:
- **Header**: Navegación principal con menú responsive
- **Hero**: Sección de bienvenida con animaciones CSS
- **TeamSection**: Presentación de los miembros del equipo
- **Skills**: Visualización de tecnologías y habilidades
- **Projects**: Galería de proyectos realizados
- **Footer**: Información de contacto y redes sociales

### 4. Estilos CSS Personalizados
Utilizamos CSS puro con:
- Variables CSS para colores y espaciados
- Flexbox y Grid para layouts responsive
- Animaciones y transiciones suaves
- Media queries para diferentes dispositivos

### 5. Funcionalidades JavaScript
Implementamos:
- Navegación suave (smooth scroll)
- Menú hamburguesa interactivo
- Animaciones al hacer scroll
- Validación de formularios
